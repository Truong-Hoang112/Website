1.0
Quản lý Tài khoản & Phân quyền
• Đăng ký / Đăng nhập (email + password)
• Đăng nhập Google OAuth 2.0
• Quên mật khẩu → OTP 6 số qua email
• Xác thực session, phân quyền admin/customer
2.0
Quản lý Sản phẩm
• CRUD sản phẩm (admin): thêm, sửa, xóa, upload gallery ≤20 ảnh
• Tìm kiếm, lọc (danh mục, thương hiệu, RAM, bộ nhớ, khoảng giá)
• So sánh ≤ 4 sản phẩm
• Đánh giá sản phẩm (khách) / Duyệt đánh giá (admin)
• Thêm/xóa yêu thích (wishlist)
3.0
Quản lý Giỏ hàng, Đơn hàng & Coupon
• Thêm / sửa / xóa sản phẩm trong giỏ hàng
• Tạo đơn hàng: COD / VNPay / MoMo (mô phỏng)
• Validate coupon: WELCOME10, VIP20, FREESHIP, SALE5TR...
• Chuyển trạng thái: pending → confirmed → shipping → delivered
• Hủy đơn + hoàn kho (nếu đã giữ hàng)
4.0
Chat Realtime (Socket.IO)
• Kết nối WebSocket kèm session cookie
• join_conversation → tham gia room theo conversation_id
• typing indicator khi đang nhập
• new_message → INSERT + broadcast cho cả khách & admin
• admin_status → trạng thái online của admin
5.0
Quản lý Marketing
• CRUD Banner (3 vị trí: hero / side / quick)
• Upload ảnh: Cloudinary (hoặc local fallback)
• CRUD Khuyến mãi (có start/end date, banner_type)
• Upload nhiều ảnh carousel hero (≤10 ảnh cùng lúc)
6.0
AI Chatbot (Gemini API)
• Gemini-3.6-flash + tool calling
• Tool 1: search_products → truy vấn MySQL
• Tool 2: get_product_detail
• Tool 3: check_stock
• Tool 4: get_order_status (yêu cầu xác minh email)
◀ AI Chatbot chỉ truy vấn chéo (read-only) các bảng products, orders, users — không sở hữu kho dữ liệu riêng. Nó là tiến trình xử lý cuối cùng.
